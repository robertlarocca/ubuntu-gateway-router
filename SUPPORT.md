# Support

## Report Issues and Get Help

This project uses GitHub issues to track bugs and feature requests. Please search the [existing issues](https://github.com/robertlarocca/ubuntu-gateway-router/issues) before filing new issues to avoid duplicates. For new issues, file your bug or feature request as a new issue.

## Support Policy

Releases may include new features, fixes (security and/or non-security), or a combination of both. Some critical issues may be fixed in a servicing update to the latest release. Support for this project is not offically provided although you may find limited support by other users and the Ubuntu community.
